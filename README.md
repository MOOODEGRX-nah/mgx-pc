# MGX(PC)

موقع كتالوج أجهزة كمبيوتر جاهزة (PC Builds) وقطعها — مصمم لتسهيل البحث على
عشاق ومستخدمي الكمبيوتر بالسوق السعودي. بدل ما يضيع الزائر وقته يبحث عن كل
قطعة بمتجر لحالها، يلقى الجهاز كامل بقطعه، روابط الشراء المباشرة، وأسماء
القطع جاهزة للنسخ — كل شي بمكان وحد.

الموقع بالعربي (افتراضي) والإنجليزي بالكامل.

## المميزات

**للزوار**
- أجهزة جاهزة حسب الفئة (High-End، Mid-Range، Budget، بديل الكونسول) مع إجمالي السعر.
- صفحة الجهاز: كل قطعة مع أفضل سعر وكل عروض المتاجر (السعر، التوفر، تاريخ التحديث، فتح/نسخ الرابط).
- إجمالي الجهاز، تنبيه الأسعار الناقصة، مجموع الإكسسوارات لحاله، مقارنة "كل شي من متجر واحد"، تحذيرات التوافق.
- تصدير PDF (فيه الروابط كاملة) ونسخ قائمة الشراء.
- فيديوهات أداء تقريبي (يوتيوب، ما يحمّل إلا بعد الضغط).
- **ركّب جهازك** (`/builder`): اختيار القطع من الكتالوج، أسعار وتوافق مباشر، حفظ المسودة في المتصفح، وإرسال التجميعة للأونر.
- **المستشار** (`/advisor`): أسئلة سريعة (الميزانية، السيت أب، نوع الألعاب، الاستخدام، الجودة، الشاشة) ← اقتراح الأجهزة المناسبة.

**للأونر** (`/admin`)
- كتالوج القطع: كيس، معالج، كرت شاشة، رام، SSD، HDD، مبرد، مزود طاقة، لوحة أم، إكسسوارات — مع المواصفات ومستوى الأداء وعروض متاجر متعددة.
- إضافة/تعديل جهاز باختيار القطع من الكتالوج، محرر صورة، فيديوهات.
- مراجعة الأسعار (قائمة العروض القديمة أو بدون سعر).
- صندوق تجميعات الزوار: التجميعات المتطابقة تندمج ويتحسب عددها، ونشرها كجهاز بضغطة.
- الإعدادات: مبلغ السيت أب للمستشار، ومدة اعتبار السعر قديم.

## التقنيات

React 19، TypeScript، Vite 8، Tailwind CSS v4، react-router 7، i18next، Supabase (Postgres + RLS + Storage)،
والنشر على GitHub Pages.

## التشغيل والأوامر

```bash
npm ci            # يحتاج Node 22 أو أحدث
npm run dev       # http://localhost:5173/mgx-pc/
npm run lint      # ESLint
npm run lint:i18n # تطابق مفاتيح الترجمة العربية والإنجليزية
npm test          # اختبارات vitest
npm run build     # نفس أمر CI
```

اختبارات قاعدة البيانات (على Postgres محلي، مو على المشروع الحقيقي): `bash supabase/tests/run.sh`
— التفاصيل في `supabase/tests/README.md`.
